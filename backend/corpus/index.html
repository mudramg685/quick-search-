QuirkPedia

A tiny encyclopedia for curious minds: computer networks, databases, algorithms, search engines and a few curiosities.

Networks

  • HTTP: The Hypertext Transfer Protocol — How browsers and servers talk: requests, responses, methods, status codes and headers.
  • TCP/IP and the Transport Layer — Reliable byte streams over an unreliable network: handshakes, acknowledgements and congestion control.
  • DNS: The Internet's Phone Book — How domain names are resolved to IP addresses through a hierarchy of name servers and caches.
  • TLS and HTTPS — Encryption, certificates and the TLS handshake that secures the web.
  • Designing REST APIs — Resources, verbs, status codes and JSON: principles for clean HTTP APIs.
  • Rate Limiting and Politeness — Token buckets, sliding windows and crawl delays that protect servers from overload.
  • The OSI Reference Model — Seven layers from physical signals to applications, and how they map onto TCP/IP.
  • Load Balancing — Spreading traffic across servers with round robin, least connections and consistent hashing.
  • Content Delivery Networks — Caching content at the network edge to cut latency for users worldwide.

Search

  • How Web Crawlers Work — Frontiers, graph traversal, politeness and duplicate detection inside a web spider.
  • The robots.txt Standard — The Robots Exclusion Protocol tells crawlers which paths they may visit.
  • The Inverted Index — The core data structure of search engines: a map from each term to the documents containing it.
  • TF-IDF Weighting — Term frequency times inverse document frequency: a classic relevance signal.
  • BM25 Ranking Function — Okapi BM25 scores documents with saturating term frequency and length normalization.
  • Tokenization — Splitting text into searchable tokens: lowercasing, punctuation and Unicode.
  • Stemming and the Porter Algorithm — Reducing words like connected, connecting and connection to a common stem.
  • Stop Words — Very common words such as the, and and of that carry little meaning for retrieval.
  • PageRank and Link Analysis — Ranking pages by the structure of the link graph using a random surfer model.
  • Search Autocomplete — Suggesting queries as you type with prefix trees and popularity ranking.
  • A Short History of Search Engines — From Archie and AltaVista to modern web search.

Databases

  • Relational Databases — Tables, keys and relations: the model behind SQL database management systems.
  • SQL Basics — SELECT, JOIN, GROUP BY and friends: querying relational data with SQL.
  • Database Normalization — First, second and third normal form: removing redundancy and update anomalies.
  • Database Indexes and B-Trees — Why indexes make lookups logarithmic and how B-trees keep them balanced.
  • Transactions and ACID — Atomicity, consistency, isolation and durability keep data correct under failures.
  • Query Optimization — How a database planner chooses join orders and access paths using statistics.
  • SQLite — The embedded, serverless SQL database engine that ships inside billions of devices.
  • PostgreSQL — A powerful open-source object-relational database with MVCC and rich indexing.
  • NoSQL Databases — Key-value, document, column and graph stores and the trade-offs they make.

Algorithms

  • Hash Tables — Constant-time lookups with hash functions, buckets and collision resolution.
  • Tries and Prefix Trees — Tree structures keyed by characters that power autocomplete and prefix search.
  • Heaps and Priority Queues — Binary heaps give O(log n) insert and extract-min, perfect for top-k selection.
  • Graph Traversal: BFS and DFS — Breadth-first and depth-first search for exploring vertices and edges.
  • Sorting Algorithms — Quicksort, mergesort, heapsort and Timsort compared.
  • Binary Search — Halving the search space to find items in sorted arrays in logarithmic time.
  • Big-O Notation and Complexity — Describing how running time and memory grow with input size.
